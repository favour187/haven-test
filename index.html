On the phone: download, open the APK, allow "install unknown apps" for the browser if asked. Haven is private — no ads, no tracking, works offline. There is no universal APK since v1.0.3: it tripled the download size; the per-ABI files are the same app, smaller.

Try it in the browser (early)

A web build of the app appears here once the web build lands. The browser version is for trying flows — your data stays in this browser, and checkout runs in the Android app.
