On the phone: download, open the APK, allow "install unknown apps" for the browser if asked. Haven is private — no ads, no tracking, works offline. The app is signed with the Haven release key, so an update installs over the previous version. There is no universal APK: it tripled the download size; the per-ABI files are the same app, smaller.

The APKs live on the private repository — if a download link opens a 404, sign in to GitHub as favour187 in this browser first, then retry.

Try it in the browser

Open the web build checking version…

This is v1.9.16 (build 39) — the current code. The browser version is for trying flows: your data stays in this browser, and checkout runs in the Android app. First load can take up to a minute while the engine downloads; after that it opens quickly.

The Android files above are the last APKs CI could finish (1.9.11) — an APK is the only thing a phone installs by hand. The current code, 1.9.16 (build 39), is packaged as a signed Play Store bundle, haven-1.9.16-39.aab, in the v1.9.16 release. A bundle cannot be sideloaded; it is what goes to Google Play. The repository is private, so those release links open a 404 unless you are signed in to GitHub as favour187. CI on this repository is paused while a GitHub billing problem is sorted out.

Offline AI models download and run on the Android build only — the on-device runtimes are not ported to the web, so the Offline AI screen says so there instead of showing buttons that cannot work.

What's new

v1.9.12 – v1.9.16 — a caregiver page for each person; snap the child's own cup or blanket and name it; Haven counts what happens on the board and writes a brief (counts, never a diagnosis); the caregiver answers with one picture and one word, which lands on the board as a tile; the role question is asked once; real photographs on the board; the app notices whether there is data and says which features need it (finding a film online, Groq, paying, sending to another phone); a film chosen online is downloaded once and then plays with no internet; a choice made with no data is kept instead of lost; each install now has its own database key; and the privacy policy covers all of it. It is also the first release with a signed Play bundle of the current code: haven-1.9.16-39.aab, 108.7 MB, arm64 and arm32, in the v1.9.16 release.

  • v1.1.3 — every platform: iOS, macOS, Windows and Linux runners added (the iOS app had never been in the repository — ios/ was git-ignored). Adaptive layout for phone, tablet, desktop and browser. Victory sound: games finish with a short, calm fanfare, with a switch to turn it off in Accessibility. Offline AI models can be imported from a file you already have, downloads show real progress and can be stopped. Added the build book for all six platforms, an APKPure submission guide and a privacy policy.
  • v1.1.2 — standards-based wearable profiles and Bluetooth Physical Activity Monitor history (steps and sleep, read straight from the watch).
  • v1.1.0 — wearables over Bluetooth LE, daily guidance, media controls, signed AAB for Google Play, worker refresh.
  • v1.0.6 — checkout can no longer hang; payments are confirmed by the server when you return to Haven.
  • v1.0.3 — wearables, on-device AI runtimes shipped in the app, game sounds, ID card and tool screens restored, Paystack checkout fixes. Downloads are per-ABI only — three APKs, no universal.
  • v1.0.2 — offline-first: on-device AI models bundled again, five real videos play offline, SOS alerts fall back to a ready-to-send message when offline.
  • v1.0.1 — big/small text applies everywhere instantly, Writing help, SOS alerts to trusted people, appointments with reminders, videos remember where you stopped.
  • v1.0.0 — first release: all four age bands, 20 features, 228 games, encrypted storage, in-app checkout.
